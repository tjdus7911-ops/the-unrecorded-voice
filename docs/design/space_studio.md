## 배치 근거
| 요소 | 위치 | 이유 |
|---|---|---|
| 출입문 | 남벽 서쪽 (중심 x=0.95) | 책상에서 문이 **등 뒤**에 있어 노크·"정우야?" 연출이 뒤에서 발생 |
| 작업 책상 | 북벽 창 앞 | 따뜻한 책상 조명 ↔ 차가운 창밖 조명 대비 (REF 02) |
| 벽시계 | 남벽 상부 | 책상에서 돌아보면 보이는 위치 — 초침 정지 이벤트 |
| 낮은 수납장 + 손전등 | 남벽, 문 옆 | 정전 후 문으로 가는 동선에서 발견 (요구사항 03 §2) |
| 카세트 선반 | 서벽 | 입구에서 들어서면 좌측에 테이프 벽 — 직업 정체성 |
| 소파·테이블 | 동벽 | 작업 외 생활 흔적 (밤샘 작업) |
| 장비 랙 | 책상 동쪽 | 카세트 데크·EQ·전원 장치 |
