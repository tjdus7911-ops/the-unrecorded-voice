# 미확정 기획 항목 (임의 확정 금지)

> 마스터 브리프 7장: "테이프의 발신 방식, 관리소장의 구체적인 은폐 행위, 유해 발견 경위는 아직 확정되지 않았다. 임의로 확정하지 말고 별도 기획 항목으로 관리한다."
> 이 목록의 항목은 **사용자 결정 전까지 코드·대사·레벨에 확정 형태로 넣지 않는다.** 구현이 필요하면 교체 가능한 플래그/플레이스홀더로 처리한다.
