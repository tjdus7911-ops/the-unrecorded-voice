# 공간 설계 — 작업실 외부 상가 복도 (cor_)

REF 03 · 2026년 · 오래된 상가 건물 3층 · 작업실(304호)과 **같은 월드 좌표** → 출입문을 열면 로딩 없이 이어진다.

## 치수·배치 (Blender 좌표, 원점 = 작업실 남서쪽 바닥 모서리)
- 복도: x −5.0 ~ 13.0 (18 m), y −2.0 ~ −0.2 (폭 1.8 m), 천장 2.5 m (석고 텍스 + 노출 형광등)
- 북쪽: 303호(x −2.6) · **304호 작업실 문(x 0.95)** · 분전함 · 안내문 · 305호(녹색 철문, x 9.0)
- 남쪽: 308호(x 2.0, 앞에 납작한 택배 상자 더미) · 셔터 내린 점포(x 4.3~6.5) · 소화전함(x 7.5) · 306호(x 9.5) · 시든 화분
- 서쪽 끝: 엘리베이터 (층 표시 "3", 호출 버튼 — 반응 없음)
- 동쪽 끝: 계단실 (x 13 ~ 15.6) — 하행·상행 계단 각 10단(단높이 0.17 m, 디딤 0.28 m), 인조석 물갈기 + 알루미늄 논슬립, 은색 원형 파이프 난간(REF 03), 비상구 유도등
- **택배 상자 위치**: 304호 문 바로 앞 (x 1.0, y −0.75)

## 재질
갈색 300 mm 세라믹 타일 바닥 · 아이보리 벽 + 1 m 높이 진한 징두리 페인트 + 몰딩 · 회색/녹색 도장 철문 · 알루미늄 셔터

## 조명 상태 (PHASE 01 테스트)
| 조명 | 상태 |
|---|---|
| 복도 형광등 6개 | 정상, 동쪽에서 두 번째(x 8.5)는 **깜빡임** (지직 소리) |
| 계단실 상행 | 정상 |
| 계단실 하행 계단참 | **고장 (완전 암흑)** — 손전등으로만 단서(열쇠) 발견 |

## 소리
형광등 험(60 Hz 전원 → 120 Hz) · 깜빡이는 등의 버즈 · 벽 너머 막힌 빗소리 · 멀리서 엘리베이터 · 타일 발소리와 긴 잔향(복도 리버브 버스)
