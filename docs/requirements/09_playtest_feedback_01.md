# 실제 플레이 테스트 결과 및 추가 수정 요청

현재 제작된 Windows 테스트 빌드를 직접 실행하고 플레이해 보았습니다.

공간 및 그래픽은 이전보다 개선되었으나 실제 게임 조작과 UI, 상호작용, 1인칭 캐릭터 표현에서 수정이 필요한 사항이 있습니다.

기존 구현 내용을 삭제하거나 처음부터 다시 개발하지 말고 현재 프로젝트를 기반으로 수정 및 개선해 주세요.

## 1. 마우스 시점 조작 오류 — 최우선 수정

실제 Windows 테스트 빌드에서 마우스가 정상적으로 작동하지 않습니다.

다음 항목을 점검하고 수정해 주세요.

- 마우스 좌우 이동에 따른 카메라 회전
- 마우스 상하 이동에 따른 카메라 회전
- Godot InputEventMouseMotion 처리
- 마우스 캡처 모드 설정
- 게임 실행 시 입력 포커스
- UI가 마우스 입력을 가로채는 문제
- 일시정지 및 조사 화면에서 입력 상태 전환
- 전체 화면 및 창 모드에서의 입력
- Alt+Tab 이후 마우스 입력 복구
- 마우스 감도
- 프레임 속도에 따른 마우스 감도 변화 방지

게임 플레이 중에는 마우스 커서를 숨기고 화면 중앙에 고정합니다.

ESC키를 눌러 일시정지하면 마우스 커서가 나타나야 합니다.

계속하기를 누르면 마우스가 다시 캡처되고 정상적으로 시점 조작이 가능해야 합니다.

에디터 또는 자동 테스트에서만 확인하지 말고 Windows Export 빌드에서 실제 마우스 입력을 검증해 주세요.

## 2. 메인 타이틀 화면 제작

게임 실행 시 바로 작업실에서 시작하지 않고 메인 타이틀 화면을 표시해 주세요.

게임명: 녹음되지 않은 목소리

영문명: THE UNRECORDED VOICE

메뉴 구성:

- 새 게임
- 이어하기
- 설정
- 게임 종료

배경은 기존에 제작한 작업실의 실제 3D 공간을 활용합니다.

녹음기, 카세트테이프, 빗물이 흐르는 창문, 책상 조명 등을 활용하여 영화적인 타이틀 화면을 제작해 주세요.

빗소리, 시계 초침, 희미한 카세트테이프 회전음이 들리도록 합니다.

일반적인 웹사이트나 모바일 앱처럼 보이는 카드형 UI, 과도한 라운드 버튼, 화려한 그라데이션은 사용하지 않습니다.

저장 데이터가 없으면 이어하기 버튼을 비활성화합니다.

## 3. 일시정지 메뉴

게임 플레이 중 ESC키를 누르면 일시정지 메뉴가 표시되도록 구현해 주세요.

메뉴 구성:

- 계속하기
- 설정
- 마지막 체크포인트에서 다시 시작
- 메인 메뉴로 돌아가기
- 게임 종료

일시정지 상태에서는 플레이어 이동, 귀신 AI, 추격, 스토리 이벤트 타이머가 중지되어야 합니다.

메인 메뉴 이동 및 게임 종료 시 확인 팝업을 표시합니다.

저장되지 않은 진행 내용이 있다면 안내해 주세요.

게임 종료 버튼은 실제 프로그램 종료까지 정상적으로 작동해야 합니다.

## 5. 1인칭 손 및 팔 모델링

현재 스크린샷에서는 손전등이 공중에 떠 있는 것처럼 보입니다.

기존에 요청한 서정우의 1인칭 손 및 팔 모델링이 실제로 구현되었는지 확인해 주세요.

미구현 상태라면 우선적으로 제작합니다.

- 현실적인 남성의 왼손과 오른손
- 손가락, 손톱, 피부 주름 및 관절
- 짙은 회색 카디건 소매
- 손가락별 리깅
- 손목 및 팔 관절 리깅
- 자연스러운 물체 파지
- 피부와 의상의 PBR 재질

손전등을 사용할 때 반드시 손으로 손전등을 쥐고 있어야 합니다.

녹음기와 카세트테이프를 조사할 때도 실제 손이 표시되어야 합니다.

## 6. 1인칭 상호작용 애니메이션

다음 행동을 단순한 오브젝트 위치 변경이나 UI 표시로 처리하지 말고 실제 손과 팔의 애니메이션을 적용해 주세요.

- 손전등 집기
- 손전등 버튼 누르기
- 문손잡이 잡기 및 문 열기
- 전등 스위치 누르기
- 택배 상자 들어 올리기
- 택배 상자 개봉
- 메모 집어 읽기
- 카세트테이프 집기
- 카세트테이프 삽입
- 녹음기 재생 및 정지 버튼 누르기
- 서랍 열기
- 열쇠 획득 및 사용

물건을 조사할 때 손가락이 물체를 관통하거나 물건이 공중에 떠 있지 않도록 처리해 주세요.

손과 물건의 움직임, 효과음이 서로 일치해야 합니다.

## 7. 오브젝트 조사 UI 개선

현재 조사 화면은 텍스트가 작고 배경과 겹쳐 가독성이 떨어집니다.

다음 방식으로 개선해 주세요.

- 조사 대상 오브젝트를 화면 중앙 가까이 표시
- 실제 손으로 물건을 들고 있는 모습
- 마우스를 이용한 오브젝트 회전
- 앞면과 뒷면 확인
- 필요 시 확대 및 축소
- 오브젝트 명칭 표시
- 설명 텍스트 가독성 개선
- 획득 가능 여부 표시
- 조사 종료 키 안내

조사 모드에서 마우스를 움직이면 오브젝트가 회전하고, 일반 플레이 시에는 카메라가 회전하도록 입력 상태를 분리합니다.

조사 종료 후에는 정상적인 카메라 조작 상태로 복귀해야 합니다.

모든 조사 대상에 불필요하게 긴 설명을 표시하지 말고 중요한 정보 위주로 구성합니다.

## 8. 택배 및 테이프 이벤트 수정

기존 프롤로그 기획과 현재 구현 흐름이 일치하는지 확인해 주세요.

정상적인 진행 순서는 다음과 같습니다.

1. 작업실에서 세 번의 노크가 들립니다.
2. 플레이어가 출입문을 엽니다.
3. 문 앞에서 택배 상자를 발견합니다.
4. 실제 손으로 택배 상자를 들어 올립니다.
5. 작업실 책상으로 가져옵니다.
6. 책상 위에 택배 상자를 내려놓습니다.
7. 상자를 개봉합니다.
8. 메모와 일곱 개의 카세트테이프를 발견합니다.
9. 메모를 읽습니다.
10. 첫 번째 테이프를 녹음기에 삽입합니다.
11. 녹음기를 재생합니다.

복도 바닥에서 택배 상자를 열고 테이프를 조사하는 것이 기본 스토리 진행이 되지 않도록 수정해 주세요.

카세트테이프는 실제 제품과 유사하게 내부 릴, 투명 케이스, 테이프 구멍, 손글씨 라벨 등의 디테일을 표현합니다.

## 9. 손전등 및 정전 이벤트

손전등을 처음부터 자동으로 소지한 상태가 아니라 기존 프롤로그 설정에 따라 획득하도록 합니다.

- 처음에는 작업실 조명이 정상적으로 작동합니다.
- 첫 번째 테이프 재생 이후 이상 현상이 발생합니다.
- 녹음기를 정지한 뒤 소은의 목소리가 등 뒤에서 들립니다.
- 출입문이 잠깁니다.
- 잠긴 출입문을 조사하면 실내 조명이 꺼집니다.
- 전등 스위치를 눌러도 켜지지 않습니다.
- 플레이어가 손전등을 찾습니다.
- 실제 손으로 손전등을 획득합니다.
- F키로 손전등을 켭니다.
- 어두운 공간에서 단서를 탐색합니다.

정전 이후에도 손전등 위치를 발견할 수 있도록 희미한 외부 조명이나 자연스러운 안내를 적용합니다.

손전등의 빛은 지나치게 좁거나 약하지 않도록 조정해 주세요.

- 자연스러운 걷기와 달리기
- 앉아서 이동
- 계단 이동
- 벽과 가구 충돌
- 문 사이 이동

- 자연스러운 가속 및 감속
- 걸음에 따른 손과 팔의 미세한 움직임
- 달리기 이후 거친 호흡
- 공포 상태에서 손 떨림

카메라가 지나치게 흔들리거나 미끄러지는 느낌이 발생하지 않도록 조정해 주세요.

## 11. 복도 그래픽 개선

현재 복도와 계단실의 기본 구조는 유지합니다.

다음 디테일을 추가하여 실제 한국 상가 건물처럼 표현해 주세요.

- 문마다 다른 호실 번호
- 오래된 안내문
- 입주 업체 명패
- 소방 점검표
- CCTV
- 전기 배선 및 배관
- 벽면의 자연스러운 오염
- 바닥 마모
- 형광등의 자연스러운 조명
- 소화기 안내 표시
- 비상구 표지판

복도를 처음부터 폐건물처럼 표현하지 않습니다.

정상적인 상가 건물이 스토리 진행에 따라 공포스럽게 변해야 합니다.

시스템 코드만 구현되어 있는지, 실제 음원이 적용되어 있는지 구분하여 보고해 주세요.

다음 사운드의 실제 재생 여부를 확인합니다.

- 소은의 한국어 대사
- 평상시 숨소리
- 달리기 숨소리
- 공포 상태의 호흡
- 놀라서 숨을 들이마시는 소리
- 심장 박동
- 바닥 재질별 발소리
- 노크
- 문 여닫는 소리
- 손전등 버튼
- 빗소리
- 형광등 소리
- 녹음기 버튼
- 카세트테이프 회전음
- 아날로그 잡음

등 뒤에서 들리는 소은의 목소리는 반드시 실제 3D 공간 음향으로 구현합니다.

임시 음원과 최종 음원을 명확하게 구분해 주세요.

## 13. 저장 및 체크포인트

자동 저장 및 이어하기 기능을 구현해 주세요.

프롤로그의 주요 체크포인트:

- 게임 시작
- 택배 획득
- 첫 번째 테이프 재생
- 손전등 획득
- 1998년 아파트 진입

저장 데이터에는 플레이어 위치, 획득 아이템, 조명 상태, 오브젝트 상태, 스토리 이벤트 진행 상태를 포함합니다.

이어하기 시 이미 완료한 이벤트가 의도치 않게 반복되거나 필수 이벤트가 누락되지 않도록 합니다.
