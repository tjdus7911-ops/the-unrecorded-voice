# 요구사항 14 — 1인칭 손 및 팔 제거와 상호작용 방식 변경 (2026-11-27 10:57, 사용자 원문)

현재 구현된 1인칭 손과 팔의 모델링, 리깅, 관절 방향 및 상호작용 애니메이션이 부자연스러워 오히려 게임의 몰입도를 떨어뜨리고 있습니다.
개발 효율성과 전체적인 게임 완성도를 고려하여 1인칭 손과 팔을 표시하지 않는 방식으로 변경합니다.

1. 손과 팔 제거
* 모든 일반 플레이 화면에서 손과 팔 모델 제거
* 손가락 및 손목 애니메이션 비활성화
* 기존 손 모델과 리깅 파일은 삭제하지 않고 별도로 보관
* 손과 팔에 의존하는 상호작용 로직 수정
* 관련 불필요한 렌더링 및 애니메이션 처리 최적화

2. 손전등
* 손전등 사용 시 손과 팔을 표시하지 않음
* 손전등 자체도 화면을 과도하게 차지하지 않도록 처리
* 손전등 모델을 표시하는 방식과 빛만 표시하는 방식의 실제 플레이 화면을 비교하여 더 자연스러운 방식 적용
* 이동 및 달리기에 따른 미세한 빛의 흔들림 유지
* 손전등 버튼 조작음 유지
* 기존 암흑 환경 및 손전등 필수 탐색 정책 유지

3. 녹음기 및 테이프
* 평상시 녹음기를 화면에 지속적으로 표시하지 않음
* 녹음기를 사용하거나 조사할 때만 화면에 표시
* 재생, 정지, 테이프 삽입 및 제거는 오브젝트 자체의 애니메이션으로 표현
* 버튼 조작음과 테이프 삽입음으로 실제 조작감을 전달
* 오브젝트가 허공에 떠다니는 것처럼 보이지 않도록 조사 화면과 일반 플레이 화면을 명확하게 구분

4. 오브젝트 상호작용
* 문과 서랍은 오브젝트 자체의 애니메이션으로 작동
* 아이템 획득 시 효과음 재생 및 인벤토리 저장
* 편지와 문서는 별도의 조사 화면에서 확인
* 기존 미니멀 상호작용 UI 정책 유지
* 과도한 아이템 강조 효과 및 위치 안내 금지

5. 몰입감 강화 — 손과 팔을 제거하는 대신 다음 요소의 완성도를 높여 주세요.
* 자연스러운 카메라 움직임 · 바닥 재질별 발소리 · 상황별 호흡음 · 심장 박동 · 공간 음향
* 문과 서랍의 물리적인 움직임 · 오브젝트 조작 효과음 · 조명 및 그림자 · 공포 이벤트 연출

6. QA 검수
손과 팔을 제거하면서 기존 기능 및 스토리 진행에 문제가 발생하지 않도록 전체 회귀 테스트를 진행해 주세요.
기존에 요청한 카메라 눈높이 수정, 암흑 환경 개선, 테이프 탐색 개선, 상호작용 UI 최소화, 음성 개선 및 프롤로그 EVENT 01~08은 그대로 유지합니다.
이전의 1인칭 손 및 팔 구현 요구사항은 본 요청으로 대체합니다.
