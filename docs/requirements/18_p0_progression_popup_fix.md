# 긴급 수정 요청 — 프롤로그 진행 불가 버그

최신 Windows 빌드를 직접 플레이한 결과, 게임 진행을 차단하는 치명적인 오류 2건이 발견되었습니다.

다른 기능 개발을 중단하고 아래 오류를 P0 우선순위로 수정해 주세요.

## 1. 게임 시작 확인 팝업 잘림 및 클릭 불가

첨부한 스크린샷을 확인해 주세요.

### 현재 문제

- 게임 시작 확인 팝업이 화면 좌측 상단에 표시됨
- 팝업의 제목과 내용이 화면 밖으로 잘림
- 일부 버튼이 정상적으로 표시되지 않음
- 버튼 클릭이 불가능함
- 팝업이 표시된 상태에서 정상적인 게임 진행이 어려움

### 수정 요구사항

- 모든 확인 팝업은 화면 정중앙에 표시
- 팝업 제목, 내용, 버튼이 모두 화면 안에 표시되도록 수정
- Godot Control, CanvasLayer, Anchor, Offset, Container 설정 전수 검수
- 창 모드, 전체 화면, 테두리 없는 창 모드에서 정상 표시
- 창 크기를 변경해도 팝업 중앙 정렬 유지
- 팝업 표시 시 마우스 커서 활성화
- 팝업 표시 중 플레이어 이동 및 카메라 조작 비활성화
- 팝업 종료 후 마우스 캡처 및 게임 조작 정상 복구
- 버튼 클릭 영역과 실제 표시 위치 일치
- 중복 팝업 발생 방지
- 팝업 표시 중 상호작용 아이콘 숨김

게임 시작 확인 팝업뿐만 아니라 게임 종료, 메인 메뉴 이동, 재시작, 설정 등 모든 팝업에 동일한 문제가 없는지 확인해 주세요.

## 2. 출입문 잠김 이후 스토리 진행 불가

### 현재 문제

첫 번째 테이프를 재생하고 출입문이 잠긴 이후 스토리가 더 이상 진행되지 않습니다.

작업실 밖으로 나갈 수 없으며 이후 공포 이벤트를 진행할 수 없습니다.

### 정상적으로 진행되어야 하는 이벤트 순서

1. TAPE 01을 녹음기에 삽입하고 재생
2. 소은 (음성): “정우야, 녹음되고 있어?”
3. 출입문이 강하게 닫힘
4. 출입문 잠금 상태 적용
5. 플레이어가 출입문을 확인
6. 정우 (자막): “왜 안 열려...?”
7. 시계 정지 및 빗소리 제거
8. 녹음기 정지
9. 플레이어 뒤쪽에서 소은 (음성): “정우야...?”
10. 정우 (자막): “누구야?”
11. 작업실과 복도 전체 정전
12. 정우 (자막): “손전등... 서랍에 있었는데.”
13. 플레이어가 손전등 획득
14. 플레이어가 출입문에 접근
15. 소은 (음성): “정우야... 여기야.”
16. 노크 효과음 재생
17. 출입문 잠금 해제
18. 플레이어가 직접 출입문을 열고 복도로 이동
19. 손전등을 통해 소은 발견
20. 소은이 사라진 이후 괴물 등장
21. 괴물의 실제 추격
22. 1998년 아파트로 전환

### 필수 검수 사항

- 각 이벤트의 발생 조건과 완료 조건 확인
- 선행 이벤트 완료 여부 확인
- 이벤트 상태값이 정상적으로 변경되는지 확인
- 음성 파일이 없거나 재생에 실패해도 다음 이벤트가 진행되는지 확인
- 음성 재생 완료 시그널이 누락되는 문제 확인
- 자막 표시 및 종료 이벤트 확인
- 손전등 획득 상태 확인
- 출입문 잠금 해제 이벤트 확인
- 출입문 충돌체 및 상호작용 활성화 여부 확인
- 팝업과 일시정지 상태로 인해 이벤트가 중단되는 문제 확인
- 저장 후 이어하기 시 이벤트 상태 복원 확인

특히 플레이어가 특정 위치를 바라보지 않거나 예상과 다른 순서로 행동했을 때 스토리가 영구적으로 멈추지 않도록 예외 처리를 적용해 주세요.

단순히 출입문의 잠금 기능을 제거하는 방식으로 수정하지 않습니다. 기존 공포 연출과 스토리 순서를 유지하면서 진행 불가의 근본 원인을 해결해 주세요.

## 3. 이벤트 디버깅 기능 추가

개발 빌드에서 다음 정보를 확인할 수 있는 디버그 기능을 추가해 주세요.

- 현재 챕터
- 현재 이벤트 ID
- 완료된 이벤트
- 다음 이벤트 발생 조건
- 충족되지 않은 진행 조건
- 출입문 잠금 상태
- 녹음기 재생 상태
- 손전등 획득 상태
- 팝업 활성화 상태
- 게임 일시정지 상태
- 이벤트 오류 로그

일반 사용자에게 배포되는 빌드에서는 디버그 UI를 노출하지 않습니다.

## 4. 전체 회귀 테스트

개별 기능만 테스트하지 말고 새 게임 시작부터 1998년 아파트 진입까지 실제로 연속 플레이하여 검수해 주세요.

다음 상황도 반드시 테스트합니다.

- 정상적인 순서로 플레이
- 문을 여러 번 열려고 시도
- 녹음기 재생 중 이동
- 대사 재생 중 ESC 입력
- 손전등을 획득한 뒤 작업실을 다시 탐색
- 팝업에서 예 또는 아니오 선택
- 게임 창 크기 변경
- Alt+Tab으로 다른 창 이동 후 복귀
- 저장 후 게임 종료 및 이어하기

## 5. 결과물 전달

- 각 오류의 정확한 발생 원인
- 수정한 파일 및 코드 목록
- 수정 전후 비교 스크린샷
- 새 게임부터 TAPE 01 진입까지 편집하지 않은 전체 플레이 영상
- 실제 Windows 실행 빌드
- 테스트 결과 및 남아 있는 오류
- GitHub 최신 소스 반영

실제 Windows 환경에서 검수하지 못한 경우 미검수로 명시해 주세요.

두 가지 진행 불가 오류가 해결되기 전까지 다음 챕터 개발 및 신규 기능 추가는 진행하지 않습니다.
