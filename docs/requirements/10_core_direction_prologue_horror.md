# 게임 핵심 방향 및 프롤로그 공포 연출 강화 요청

기존 개발 프로젝트에 다음 핵심 방향을 반영해 주세요.

본 게임은 Steam 출시를 목표로 하는 한국 배경의 1인칭 3D 심리 공포게임입니다.

## 1. 핵심 개발 목표

- 스트리머가 실제로 놀라고 소리 지를 만한 공포 연출
- 점프스케어에만 의존하지 않는 심리적 공포
- 플레이어가 예상하지 못하는 스토리 반전
- 일반 엔딩과 숨겨진 엔딩
- 숨겨진 단서와 재플레이 요소
- 한국어, 영어, 일본어 지원
- 한국 특유의 공간 및 시대적 분위기

## 2. 프롤로그 공포 이벤트 강화

기존 EVENT 01~08의 기본 흐름을 유지하되 다음 연출을 추가해 주세요.

### EVENT 01. 정상 작업실

정상적인 조명과 환경음을 유지합니다.

플레이어가 작업실을 안전한 공간으로 인식하도록 연출합니다.

### EVENT 02. 택배 발견

세 번의 노크 이후 문 앞에서 택배를 발견합니다.

택배를 집어 들고 돌아가려는 순간 복도 끝에서 철제 문이 닫히는 소리가 들립니다.

복도 끝 형광등 하나가 꺼집니다.

귀신의 직접적인 모습은 보여주지 않습니다.

### EVENT 03. 첫 번째 테이프

택배를 작업실 책상으로 가져와 개봉합니다.

메모와 일곱 개의 카세트테이프를 발견합니다.

첫 번째 테이프를 재생하면 소은이의 목소리가 들립니다.

소은: "정우야, 녹음되고 있어?"

정우: "...내 이름을 어떻게 알지?"

천장 조명이 한 번 깜빡입니다.

### EVENT 04. 등 뒤의 목소리

녹음기를 정지한 약 3초 뒤 플레이어의 등 뒤에서 소은의 목소리가 들립니다.

소은: "정우야?"

정우의 놀란 호흡을 재생합니다.

뒤를 돌아보면 아무도 없습니다.

다시 녹음기를 바라보면 릴이 혼자 회전하고 있습니다.

### EVENT 05. 공간의 미세한 변화

벽시계 정지, 빗소리 소멸, 모니터 잡음, 출입문 잠금 이벤트를 실행합니다.

플레이어의 시야 밖에서 다음 변화가 발생하도록 구현합니다.

- 책상 의자의 방향 변경
- 어린아이 그림 등장
- 카세트테이프 한 개 사라짐

오브젝트가 플레이어 눈앞에서 부자연스럽게 순간 이동하지 않도록 합니다.

### EVENT 06. 정전

잠긴 출입문을 조사하면 실내 조명이 모두 꺼집니다.

전등 스위치는 작동하지 않습니다.

책상 서랍에서 손전등을 획득하도록 합니다.

손전등을 찾는 동안 어린아이의 발소리가 공간 내에서 발생합니다.

동적 호흡과 심장 박동 시스템을 연동합니다.

### EVENT 07. 첫 번째 점프스케어

손전등을 사용하여 책상 밑에서 사라진 카세트테이프를 발견하도록 합니다.

플레이어가 몸을 숙여 테이프를 집는 순간 책상 반대편에서 소은의 얼굴이 짧게 나타납니다.

소은: "찾았다."

실제 3D 캐릭터 모델과 애니메이션을 사용합니다.

정우의 놀란 호흡과 손전등의 짧은 흔들림을 연동합니다.

소은이는 플레이어를 공격하지 않으며 짧은 등장 이후 사라집니다.

이 장면은 반복 재생하지 않습니다.

획득한 테이프의 뒷면에는 숨겨진 엔딩과 연결되는 추가 녹음 단서를 배치합니다.

### EVENT 08. 공간 전환

다시 세 번의 노크가 들립니다.

소은: "정우야, 여기야."

출입문 잠금이 해제됩니다.

문을 열면 1998년 한국 복도식 아파트가 나타납니다.

플레이어가 문턱을 통과한 이후 작업실로 돌아갈 수 없도록 자연스럽게 공간을 전환합니다.

복도 끝에 소은이가 나타났다가 사라집니다.

TAPE 01 — 평범했던 하루 타이틀을 표시합니다.

## 3. 공포 연출 원칙

- 핵심 이벤트는 플레이어 행동을 기반으로 실행합니다.
- 무작위 점프스케어를 반복하지 않습니다.
- 귀신이 등장하기 전 소리와 환경 변화를 통해 긴장감을 형성합니다.
- 정적과 평온한 구간을 충분히 배치합니다.
- 갑작스러운 음량 증가만으로 공포를 유발하지 않습니다.
- 플레이어의 조작권을 불필요하게 빼앗지 않습니다.
- 과도한 조명 깜빡임과 카메라 흔들림을 방지합니다.
- 프롤로그에서는 공격 및 사망 이벤트를 발생시키지 않습니다.

## 4. 엔딩 및 숨겨진 단서 시스템

일반 엔딩과 숨겨진 엔딩을 지원하도록 데이터 구조를 설계해 주세요.

각 챕터에 숨겨진 녹음 조각과 증거를 배치할 수 있어야 합니다.

필수 진행 단서와 선택적 숨겨진 단서를 구분합니다.

숨겨진 단서를 모두 발견하지 않아도 일반 엔딩에 도달할 수 있어야 합니다.

단서 획득 여부는 저장 데이터에 포함합니다.

챕터 재플레이와 숨겨진 단서 회수 기능도 고려해 주세요.

정확한 엔딩 해금 조건과 추가 대사는 기획 검토 후 확정합니다.

## 5. 다국어 시스템

초기 개발 단계부터 한국어, 영어, 일본어를 지원할 수 있도록 현지화 구조를 설계해 주세요.

Godot TranslationServer 및 번역 리소스를 활용하는 방식을 검토합니다.

- 메인 메뉴
- 설정
- 조작 안내
- 조사 UI
- 오브젝트 설명
- 스토리 대사
- 자막
- 효과음 설명
- 문서 및 단서
- 엔딩
- 크레딧

텍스트를 코드에 직접 하드코딩하지 않습니다.

음성 언어와 자막 언어는 독립적으로 설정할 수 있도록 합니다.

한국어, 영어, 일본어 폰트의 정상 출력과 글자 잘림 여부를 테스트합니다.

한국어로 작성된 실제 공간의 간판과 문서 이미지는 한국적 분위기를 위해 유지하고, 조사 시 선택한 언어의 번역을 제공합니다.

유료 음성 생성 및 번역 서비스는 임의로 결제하지 않습니다.

## 6. 한국적 공간 구현

현대 작업실과 상가 복도는 실제 한국 건물의 특징을 반영합니다.

1998년 아파트, 놀이터, 경비실, 가정집, 초등학교, 지하 기계실은 당시 한국의 실제 공간 자료를 참고하여 제작합니다.

일본식 주택, 서양식 학교 및 시대에 맞지 않는 현대 물건을 무분별하게 사용하지 않습니다.

## 7. 현재 개발 상태 확인

다음 질문에 구체적으로 답변해 주세요.

1. 현재 프롤로그 EVENT 01~08 중 실제 플레이 가능한 이벤트는 무엇인가요?
2. 자동 테스트가 아닌 실제 게임에서 정전과 조명 변화가 발생하나요?
3. 소은이의 실제 3D 캐릭터 모델은 제작되었나요?
4. 소은이의 한국어 음성은 실제 적용되었나요?
5. 플레이어 뒤에서 발생하는 방향성 음향이 구현되었나요?
6. 플레이어 시야 밖에서 오브젝트를 변경하는 이벤트 시스템이 있나요?
7. 손전등을 사용한 단서 탐색과 점프스케어를 연동할 수 있나요?
8. 현재 숨소리와 심장 박동은 실제 플레이 상태에 따라 변화하나요?
9. 다국어 지원을 위해 기존 코드를 얼마나 수정해야 하나요?
10. 숨겨진 단서 및 엔딩 분기 시스템은 구현되었나요?
11. 1998년 아파트 복도 전환까지 구현하려면 어떤 에셋이 추가로 필요한가요?
12. 현재 개발 환경에서 구현할 수 없는 기능이나 필요한 외부 도구가 있나요?

구현 완료, 부분 구현, 미구현, 검증 불가를 구분하여 답변해 주세요.

## 8. 개발 우선순위

기존에 요청한 마우스 조작 오류, 게임 메뉴, 1인칭 손과 팔, 상호작용 문제를 먼저 해결합니다.

이후 프롤로그의 공포 이벤트를 순서대로 구현합니다.

전체 챕터를 동시에 제작하지 말고 프롤로그를 처음부터 끝까지 플레이할 수 있는 수준으로 완성해 주세요.

실제 Windows 테스트 빌드와 사운드가 포함된 플레이 영상을 제공해 주세요.

기존 스토리의 핵심 반전과 등장인물 설정은 임의로 변경하지 않습니다.
