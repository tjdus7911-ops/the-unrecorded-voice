# 레퍼런스 시트 텍스트 정리 (REF 01 ~ 21)

> 사용자가 전달한 레퍼런스 이미지 시트(14장)의 **텍스트·지시사항**을 옮긴 문서다.
> 이미지 원본은 출처·라이선스가 확인되지 않은 웹 이미지가 섞여 있어 **공개 저장소에 커밋하지 않고** `refs_local/`(git 제외)에 로컬로만 보관한다.
> 레퍼런스는 분위기·구조 참고용이며, 어떤 이미지도 그대로 복제하지 않는다.

## REF 01. 전체 그래픽 스타일
- 현실적인 1인칭 3D 공포게임
- 영화처럼 자연스러운 조명과 그림자
- 실제 사람이 생활하는 듯한 공간
- 저폴리곤, 카툰 스타일 배제
- 과도한 화면 노이즈 및 VHS 필터 배제
- (이미지: 어수선한 사무실 책상·서랍·서류, 카펫 벽걸이가 있는 거실, 낡은 TV·괘종시계가 있는 방 — 따뜻한 단일 광원 + 차가운 창광)

## REF 02. 2026년 음성 복원 작업실
- 게임의 시작 공간이자 각 챕터를 연결하는 메인 공간.
- 처음에는 평범한 작업실이지만 테이프를 재생할수록 공간에 이상 현상이 발생한다.
- (이미지: 릴 테이프 데크·카세트·파형 모니터·스탠드 조명의 따뜻한 책상 / 큰 창 너머 비 내리는 도시 야경)
- ⚠ 이미지 일부의 보라·네온 색감은 마스터 브리프의 "불필요한 보라색, 네온 조명 금지"에 따라 **채택하지 않는다**. 창밖 도시광은 차가운 청회색 계열로 절제.

## REF 03. 작업실 외부 복도
- 택배 상자를 발견하는 장소. 현실적인 한국 상가 건물의 느낌을 살린다.
- (이미지: 갈색 타일 바닥 + 매립 형광등 상가 복도 / 에폭시 바닥 + 셔터 / 은색 원형 난간이 있는 콘크리트 계단)

## REF 04. 1998년 복도식 아파트 외관
- 이 아파트는 게임 전체 사건의 중심이 되는 장소이므로 챕터마다 일관된 건물 구조를 유지해야 한다.
- (이미지: 아이보리 벽 + 콘크리트 난간벽 외부 복도 / 현관 옆 계량기함 / 녹색 철제 난간 연결 통로 / 붉은 벽돌 + 흰 발코니 저층 아파트)

## REF 05. 아파트 내부 복도 및 계단
- 1990년대 한국 특유의 녹색 난간, 철제 현관문, 콘크리트 벽, 형광등 등을 반영한다.
- (이미지: 천장 배관·창살·계량기가 있는 어두운 중복도 / 인조석 물갈기 계단 + 목재 손잡이 / 하늘색 현관문 외부 복도)

## REF 06. 1998년 놀이터
- 소은이와 정우가 함께 놀았던 장소. 초반에는 평범하고 따뜻하지만 이후 기억이 왜곡되면서 공포스러운 공간으로 변한다.
- (이미지: 모래 바닥·타이어·철제 그네 / 원색 미끄럼틀 / 안개 낀 밤의 폐놀이터)

## REF 07. 경비실 및 관리사무소
- 경비원의 근무일지와 관리소장의 은폐 기록을 발견하는 장소.
- ⚠ 이미지의 CCTV 모니터·평면 모니터는 2026년 모습. **1998년 버전은 CCTV 없이** 브라운관 TV·전화기·근무일지·열쇠함 위주로 재구성.

## REF 08. 지하 기계실
- 소은이가 갇혔던 사건의 핵심 장소. 게임 후반부에서 가장 중요한 공간이다.
- (이미지: 녹슨 대형 배관·붉은 밸브 핸들·압력계·철제 사다리 / 갈라진 콘크리트 바닥과 좁은 계단)

## REF 09. 1998년 가정집
- 주민들의 증언과 기억을 탐색하는 공간. 시대적 고증이 중요하다.
- (이미지: 꽃무늬 소파 커버·장식장 거실 / 장판 바닥 어린이 책상 / 자개장·브라운관 TV·앉은뱅이 상)

## REF 10. 주요 오브젝트
휴대용 녹음기(소형 카세트 레코더) · 카세트테이프 + 손글씨 인덱스 카드 · 음성 복원 장비(카세트 데크, 우드 사이드) · 철제 현관문(녹색) · 형광등(방폭형 튜브) · 택배 상자 · 브라운관 TV(토끼귀 안테나) · 아날로그 전력량계 · 근무일지(SECURITY LOGBOOK)
- ⚠ 현관문 이미지의 **디지털 도어락은 1998년에 배치 금지**(REF 09 규칙). 1998년 문은 원통형 손잡이 + 보조 열쇠 자물쇠.

## REF 11. 서정우 — 현재 (37세, 음성 복원 전문가)
- 평범한 한국인 남성 / 약간 피곤해 보이는 눈 / 정돈되지 않은 검은 머리 / 회색 셔츠와 짙은 카디건 / 마른 체형 / 무뚝뚝하고 차분한 인상
- **처음부터 악역처럼 보이면 안 됨.**

## REF 12. 서정우 — 어린 시절 (9세, 초등학생)
- 짧은 검은 머리 / 남색 줄무늬 상의 / 베이지색 바지 / 오래된 운동화 / 평범하고 장난기 있는 인상
- 현재 정우와 눈매 및 얼굴 특징이 연결되어야 함.

## REF 13. 한소은 — 생전 (9세, 초등학생)
- 턱까지 오는 단발머리 / 노란색 카디건 / 흰색 티셔츠 / 청 멜빵바지 / 빨간색 운동화 / 휴대용 카세트 녹음기
- 밝고 호기심이 많으며 친근한 인상. 노란색 카디건을 캐릭터의 상징으로 사용.

## REF 14. 한소은 — 기억 속 모습
- 생전과 동일한 얼굴 및 복장 / 창백한 피부 / 빛바랜 노란색 카디건 / 희미하게 왜곡되는 실루엣 / 감정을 알 수 없는 표정
- 플레이어를 공격하지 않음. 초반에는 무섭지만 후반에는 안타까움을 느끼게 하는 존재.

## REF 15. 박만수 — 경비원 (사건 당시 58세)
- 짙은 남색 경비복 / 오래된 경비 모자 / 주름진 얼굴 / 굽은 어깨 / 손전등과 열쇠 꾸러미
- 악인보다는 겁이 많고 소극적인 사람처럼 표현.

## REF 16. 최영식 — 관리소장 (사건 당시 46세)
- 단정한 가르마 / 얇은 금속테 안경 / 회갈색 양복 / 흰색 셔츠 / 권위적이고 사무적인 인상
- 자신의 지위와 책임을 지키기 위해 사건을 은폐한 인물.

## 공포 캐릭터 원칙
귀신은 일반적인 좀비나 처녀귀신보다 **각 인물이 외면했던 진실을 시각적으로 표현한 괴물**로 만든다.

## REF 17. 순찰자 (The Watchman) — 경비원의 왜곡된 기억
- 얼굴이 매끈하게 지워져 있음 / 비정상적으로 긴 팔 / 아래로 꺾인 목 / 낡은 경비복 / 손전등을 들고 순찰
- 소리를 감지하여 플레이어를 추격한다.

## REF 18. 방관자 (The Bystander) — 주민들의 집단적인 기억
- 몸 곳곳에 존재하는 눈 / 얼굴을 가리고 있는 손 / 1990년대 평범한 주민 복장 / 부자연스럽게 움직이는 관절
- 플레이어가 시선을 돌리는 순간 접근한다.

## REF 19. 관리인 (The Keeper) — 관리소장의 왜곡된 기억
- 약 2.3m의 비정상적인 신장 / 낡은 회갈색 양복 / 얼굴이 없는 머리 / 손에 매달린 수많은 열쇠 / 길고 마른 손가락
- 문을 잠그고 플레이어의 이동 경로를 차단한다.
- ⚠ 레퍼런스 이미지는 기존 인터넷 괴담 캐릭터(정장·무면 장신)와 실루엣이 매우 가깝다. **복제 금지 원칙**에 따라 회갈색 1990년대 관리직 양복, 굽은 자세, 열쇠 다발 실루엣, 안경테 흔적 등 최영식에게서 파생된 고유 요소로 차별화한다.

## REF 20. 잡음 (The Static) — 정우가 왜곡하고 외면한 기억
- 검은 카세트테이프 필름으로 이루어진 신체 / 형태가 불규칙하게 변하는 얼굴 / 아날로그 잡음처럼 떨리는 실루엣 / 인간의 형태를 불완전하게 모방 / 움직일 때 들리는 뒤틀린 음성
- 후반부에 등장하는 핵심 공포 캐릭터.

## REF 21. 손전등
- 검은색 손잡이와 금속 재질 (이미지: 세로 홈 그립 + 상단 슬라이드 스위치 + 빨간 표시등의 원통형 손전등)
- 실제 버튼을 눌러 켜고 끄는 애니메이션
- 중앙은 밝고 가장자리로 갈수록 어두워지는 빛
- 벽과 사물에 자연스럽게 반응하는 조명과 그림자
- 플레이어가 움직일 때 자연스럽게 흔들리는 손전등

### 손전등을 활용한 공간 연출
- **전기가 끊긴 지하 기계실** — 손전등으로 차단기와 시설 도면을 찾아 전력을 복구해야 한다.
- **불이 들어오지 않는 아파트 복도** — 벽에 남겨진 낙서와 소은이가 남긴 흔적을 발견한다.
- **잠긴 지하 창고** — 어둠 속에서 열쇠, 녹음테이프, 사건 관련 서류를 찾는다.
- **귀신이 출몰하는 복도** — 손전등을 비추면 멀리 서 있는 귀신을 발견할 수 있지만, 귀신 역시 빛을 감지할 수 있다.

### 넣고 싶은 연출 (사용자 제안)
플레이어가 복도를 손전등으로 비췄는데 아무도 없다. 잠깐 바닥에 떨어진 테이프를 조사하고 다시 복도를 비추면 저 멀리 소은이가 서 있다. 소은이를 따라가면 사라지고, 그 자리에 새로운 단서가 놓여 있다.

배터리는 일단 **무제한**. 이 게임은 생존 자원 관리보다는 스토리와 추리가 중심이다. 귀신별 손전등 반응은 기획 초안이며, 실제 플레이에서 너무 어렵거나 불편하면 조정한다.
