# 요구사항 21 — 스토리 진행 안내 마커(Objective Marker) 시스템 (2026-11-27 16:49, 사용자 원문)

첨부한 공포게임 레퍼런스 이미지처럼 플레이어가 다음에 해야 할 행동과 이동해야 할 위치를 직관적으로 알 수 있도록 목표 위치 마커(Objective Marker) 시스템을 추가해 주세요.
현재 게임에서는 다음 행동에 대한 안내가 부족하여 플레이어가 불필요하게 헤매거나 스토리 진행이 중단된 것으로 오해할 수 있습니다.

## 1. 마커 디자인
* 첨부 레퍼런스와 유사한 노란색 위치 핀 형태
* 중앙에 작은 원형 구멍이 있는 심플한 아이콘
* 1920×1080 기준 약 24~28px 크기
* 실제 3D 공간의 목표 오브젝트 위에 표시
* 플레이어의 카메라 방향에 맞춰 항상 정면으로 표시
* 거리에 따라 지나치게 커지거나 작아지지 않도록 처리
* 별도의 텍스트, 거리 숫자, 강조 테두리 사용 금지
* 과도한 깜빡임 및 발광 효과 금지
* 기존 중앙 조준점 및 손 모양 상호작용 아이콘 유지

## 2. 마커 표시 정책
모든 상호작용 가능한 오브젝트에 마커를 표시하지 않습니다.
현재 스토리 진행에 반드시 필요한 다음 행동에만 마커를 표시합니다.
* 기본적으로 한 번에 하나의 목표 마커만 표시
* 해당 행동 완료 시 기존 마커 즉시 제거
* 다음 이벤트 활성화 시 새로운 목표 위치에 마커 표시
* 일반 조사 오브젝트에는 마커 미표시
* 숨겨진 증거 및 히든 엔딩 단서에는 마커 미표시
* 귀신 및 괴물의 위치에는 마커 미표시
* 벽이나 닫힌 문 너머의 아이템 위치를 직접 노출하지 않음
* 다른 공간으로 이동해야 하는 경우 해당 공간의 출입구에 마커 표시

## 3. 프롤로그 적용 순
(메시지가 여기서 끊겨 도착 — 아래는 첨부 이미지(refs_local/req21_marker_ref.png)의 표)

| 진행 상황 | 마커 표시 위치 |
|---|---|
| 노크 소리가 들림 | 작업실 출입문 |
| 택배 발견 | 택배 상자 |
| 택배를 가져옴 | 작업실 책상 |
| 상자 개봉 | TAPE 01 |
| 테이프 획득 | 녹음기 |
| 테이프 삽입 | 재생 버튼 |
| 정전 발생 | 손전등이 들어 있는 서랍 |
| 손전등 획득 및 잠금 해제 | 출입문 |
| 괴물 추격 | 탈출해야 하는 방향 |
| 챕터 완료 후 작업실 복귀 | 다음 테이프 |

(이미지 설명: "서랍 위에 다음 행동을 안내하는 노란색 마커 표시")

## 4. TAPE 01 이후 적용
* 새로운 공간에 진입하면 필수 이동 경로 안내
* 필수 단서를 찾아야 하는 경우 해당 단서가 있는 공간의 입구에 마커 표시
* 공간 내부에서는 플레이어가 직접 단서를 탐색하도록 구성
* 필수 단서 획득 후 다음 진행 위치에 마커 표시
* 추격 상황에서는 탈출 가능한 경로 안내
* 작업실 복귀 후 다음 테이프에 마커 표시

모든 챕터에 공통으로 사용할 수 있는 재사용 가능한 시스템으로 구현합니다.

## 5. 설정 기능
설정 > 게임플레이에 목표 위치 안내 항목을 추가합니다.
* 항상 표시: 현재 진행 목표에 마커 표시
* 막힐 때만 표시: 일정 시간 동안 진행하지 못했을 때 마커 표시
* 표시 안 함: 마커 없이 직접 탐색

기본값은 항상 표시로 설정합니다.
설정값은 게임 종료 이후에도 유지합니다.

## 6. 기술 구현 및 오류 방지
* Godot의 기존 스토리 이벤트 상태 관리 시스템과 연동
* 이벤트별 목표 오브젝트 지정
* 목표 완료 시 자동으로 마커 제거 및 갱신
* 완료된 목표에 마커가 남아 있는 오류 방지
* 획득하거나 제거된 오브젝트에 마커가 남는 오류 방지
* 저장 및 이어하기 시 현재 목표 마커 정상 복원
* 팝업, 메뉴, 오브젝트 조사 화면에서는 마커 숨김
* 챕터 전환 및 암전 중 마커 숨김
* 해상도 및 창 크기 변경 대응
* 마커 자체가 상호작용 RayCast를 방해하지 않도록 처리

마커 시스템은 진행을 안내하는 보조 기능으로만 사용하며, 마커 표시 여부가 실제 스토리 이벤트의 진행 조건에 영향을 주어서는 안 됩니다.

## 7. 검수 요청
새 게임 시작부터 프롤로그 종료 및 TAPE 01 진입까지 실제 플레이하며 모든 목표 마커가 올바른 순서와 위치에 표시되는지 확인해 주세요.
기존의 모든 오브젝트에 아이템명과 E키 안내를 표시하지 않는 정책은 유지합니다.
첨부한 레퍼런스처럼 간결한 노란색 위치 마커만 추가해 주세요.
수정된 Windows 실행 빌드와 전체 플레이 영상을 전달하고, 실제 검수하지 못한 항목은 미검수로 명시해 주세요.
