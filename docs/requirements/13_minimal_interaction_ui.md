# 요구사항 13 — 상호작용 UI를 Amnesia 시리즈와 유사한 미니멀 방식으로 (2026-11-27 10:28, 사용자 원문)

상호작용 UI를 Amnesia 시리즈와 유사한 미니멀 방식으로 변경해 주세요.

* 기본 상태에서는 화면 중앙에 2~3px 크기의 작은 조준점만 표시합니다.
* 상호작용 가능한 물건에 약 0.8~1.2m 이내로 접근하고 정확히 바라볼 경우에만 작은 손 모양 아이콘으로 변경합니다.
* 물건 이름, E키 안내, 획득 문구, 외곽선, 발광 효과는 기본적으로 제거합니다.
* 시선을 다른 곳으로 돌리면 즉시 일반 조준점으로 돌아갑니다.
* 정전 상태에서는 손전등으로 비추거나 실제 조명이 닿아 식별 가능한 물건에만 상호작용 아이콘을 표시합니다.
* 닫힌 서랍이나 상자 내부의 아이템은 미리 선택할 수 없어야 합니다.
* 잠긴 문과 일반 문은 동일한 손 아이콘을 사용하고, 직접 조작했을 때 잠겨 있다는 사실을 알 수 있도록 합니다.
* 최초 조작 튜토리얼에서만 E키 사용 방법을 안내합니다.
* 필수 단서는 실제 라벨, 공간 배치, 주인공 독백을 통해 자연스럽게 발견할 수 있도록 합니다.
* 최초 손전등 획득 구간은 완전한 암흑으로 인해 진행이 막히지 않도록 별도로 설계합니다.
* 설정에서 상호작용 힌트 및 조준점 표시 여부를 변경할 수 있도록 합니다.

상호작용 거리는 실제 플레이 테스트를 통해 조정하고, 기존의 과도한 안내 UI는 전부 제거해 주세요.

(참고: 요구사항 12 §4의 "선택 가능한 아이템에 은은한 강조 효과", "[E] 첫 번째 테이프 획득" 문구는 이 요구사항으로 대체 — 강조·문구는 설정의 '상호작용 힌트'를 켰을 때만)
