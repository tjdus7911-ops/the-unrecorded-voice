# PHASE 01 전체 플레이 QA 및 완성도 개선 요청

현재 전달받은 Windows 빌드를 직접 플레이한 결과, 실제 플레이 환경에서 여러 문제가 확인되었습니다.

첨부한 실제 플레이 스크린샷을 참고해 주세요.

현재 신규 챕터 및 신규 콘텐츠 개발을 중단하고 기존 프롤로그의 전체 기능, 그래픽, 조작, 애니메이션, UX를 검수하고 수정해 주세요.

단순히 모델과 기능이 존재하는 것을 완료 기준으로 삼지 않습니다. 실제 플레이에서 자연스럽게 작동해야 합니다.

## 1. 1인칭 카메라 및 플레이어 신체 비율 수정

현재 플레이어의 시선이 지나치게 높게 설정되어 있어 비정상적으로 키가 큰 사람이 공간을 돌아다니는 것처럼 보입니다.

- 플레이어 신장 기준 약 175cm
- 기본 카메라 눈높이 약 163~165cm
- 앉기 및 웅크리기 시 카메라 높이 자연스럽게 변경
- 카메라와 플레이어 충돌체 높이 일치
- 책상, 의자, 문, 손잡이 등 실제 규격 검수
- 기본 수직 FOV 65~75도 범위에서 실제 플레이 테스트 후 결정
- FOV 사용자 설정 지원
- 이동 시 과도한 카메라 흔들림 방지
- 계단 이동 시 시점이 갑자기 튀는 현상 방지

카메라 위치만 낮추는 것이 아니라 플레이어 신체, 충돌체, 상호작용 거리까지 함께 검수해 주세요.

## 2. 1인칭 손과 팔 전체 수정

현재 손의 방향이 뒤집혀 있으며 손목, 손가락, 물건을 쥐는 자세가 매우 부자연스럽습니다.

Blender에서 손 모델과 리깅을 다시 검수하고 실제 Godot 플레이 화면에 적용해 주세요.

- 좌우 손 모델 구분 확인
- 손바닥과 손등 방향 확인
- Bone Rotation 및 Transform 확인
- 좌우 반전 과정에서 발생한 음수 스케일 확인
- 손목의 비정상적인 회전 및 꺾임 수정
- 손가락 관절 및 물건을 쥐는 자세 수정
- 손과 팔의 실제 인체 비율 적용
- 소매와 손목 연결부 수정
- 손과 물건 사이의 관통 현상 제거
- 손가락이 물건 내부로 들어가는 현상 제거
- 카메라 회전에 따른 손과 팔의 비정상적인 회전 방지

Resident Evil 7, Outlast, Amnesia: The Bunker 등의 실제 1인칭 플레이 화면을 참고해 주세요.

## 3. 손전등 및 녹음기 사용 자세 개선

손전등과 녹음기를 항상 양손에 들고 있을 필요는 없습니다.

상황에 따라 자연스럽게 장비를 들어 올리거나 내리는 방식으로 변경해 주세요.

필요한 상태:

- 빈손 대기
- 손전등 꺼내기
- 손전등 들기
- 손전등 내리기
- 손전등 켜기 및 끄기
- 녹음기 꺼내기
- 녹음기 확인
- 녹음기 버튼 조작
- 테이프 삽입 및 제거
- 양손 장비 사용
- 달리기 중 장비를 낮추는 자세
- 물건 조사 및 획득

손전등의 실제 방향과 빛이 조사되는 방향이 일치해야 합니다.

손과 장비가 화면 중앙을 지나치게 가리지 않도록 하고, 화면 아래쪽에 자연스럽게 배치해 주세요.

## 4. 상자 개봉 및 테이프 탐색 UX 개선

현재 상자를 개봉한 후 첫 번째 테이프를 찾기가 어렵습니다.

필수 스토리 아이템을 찾는 과정에서 불필요한 혼란이 발생하지 않도록 수정해 주세요.

- 테이프 7개를 순서대로 정리하여 배치
- TAPE 01~07 번호를 실제 테이프 라벨에 표시
- 플레이 화면에서 번호를 읽을 수 있도록 텍스처 해상도 개선
- 상자를 개봉하면 테이프 전체를 확인할 수 있는 조사 시점 제공
- 첫 번째 테이프에 시선을 두면 상호작용 안내 표시
- 테이프 선택 범위 및 Raycast 충돌체 개선
- 선택 가능한 아이템에 은은한 강조 효과 적용
- 테이프를 획득하면 상자에서 실제로 사라지도록 처리
- 획득한 테이프는 인벤토리와 연동
- 첫 번째 테이프를 획득하기 전에는 다음 스토리 이벤트가 발생하지 않도록 처리

상자 개봉 후 정우의 음성을 통해 자연스럽게 안내합니다.

정우: "번호가 적혀 있네. 첫 번째 것부터 들어볼까?"

화면에 현재 목표를 짧게 표시합니다.

현재 목표: 첫 번째 테이프를 녹음기에 넣으세요.

목표 안내는 스토리 진행에 따라 자동으로 갱신하고 완료되면 사라지도록 합니다.

## 5. 전체 상호작용 UX 검수

모든 상호작용 가능한 오브젝트를 직접 검수해 주세요.

- 출입문
- 문손잡이
- 전등 스위치
- 책상 서랍
- 택배 상자
- 편지
- 테이프 7개
- 녹음기
- 손전등
- 모니터
- 기타 조사 가능한 오브젝트

공통 검수 기준:

- 바라보는 물건과 실제 선택되는 물건이 일치하는가?
- 상호작용 가능 거리가 자연스러운가?
- 안내 문구가 적절하게 표시되는가?
- 물건을 획득하는 손 애니메이션이 존재하는가?
- 물건을 조사할 때 카메라가 부자연스럽게 움직이지 않는가?
- 물건 조사 종료 후 정상적인 이동과 시점 조작이 가능한가?
- 상호작용을 반복해도 오류가 발생하지 않는가?
- 물건을 획득할 수 없는 상태에서 잘못된 안내가 표시되지 않는가?

# (같은 메시지) 추가 수정 요청 — 암흑 환경 및 손전등 필수 탐색 시스템

현재 정전 상태에서도 공간이 지나치게 밝아 손전등 없이 이동하거나 단서를 찾을 수 있습니다.
공포게임의 긴장감과 손전등의 활용도를 높이기 위해 조명 시스템을 전면 재검수해 주세요.

1. 정전 상태 개선
- 정전 발생 시 실내의 모든 일반 조명을 완전히 소등합니다.
- Environment Ambient Light, Sky Light, 간접광, 반사광, GI, Emission 등 잔여 광원도 검수합니다.
- 자동 노출 기능으로 인해 어두운 공간이 다시 밝아지는 현상을 방지합니다.
- 창문을 통해 들어오는 외부 조명도 최소화합니다.
- 손전등 없이 가구, 문, 단서의 세부 형태를 식별하기 어려워야 합니다.
- 단순히 검은색 화면 필터를 덮는 방식이 아니라 실제 3D 조명 환경을 수정합니다.

2. 손전등 조명 개선
- 손전등이 비추는 영역만 명확하게 확인할 수 있도록 합니다.
- 빛의 중심부는 밝고 가장자리로 갈수록 자연스럽게 어두워지도록 합니다.
- 거리에 따른 빛의 감쇠를 적용합니다.
- 손전등 방향과 실제 빛의 조사 방향을 일치시킵니다.
- 벽과 가구를 통과하여 빛이 비치는 현상을 방지합니다.
- 오브젝트에 의해 자연스러운 그림자가 생성되도록 합니다.
- 손전등을 켜더라도 방 전체가 밝아지지 않도록 합니다.
- 손전등이 비추지 않는 영역은 어둠을 유지합니다.

3. 공간별 조명 상태 (각각 독립 구현·검수)
- 정상 점등 / 부분 소등 / 조명 고장(스위치 무반응) / 완전 정전 / 비상등(제한된 붉은 조명) / 손전등 점등 / 초자연적 이상 현상(손전등 깜빡임·꺼짐)

4. 프롤로그 정전 연출
1) 천장 조명 불규칙 깜빡임 2) 전기 차단 효과음과 함께 모든 실내 조명 소등 3) 모니터·전자기기 화면 꺼짐
4) 정우가 놀라며 숨을 들이마심 5) 잠시 정적 6) 정우: "서랍에 손전등이 있었는데..."
7) 책상 서랍에서 손전등 찾기 8) 실제 손으로 집어 드는 애니메이션 9) 버튼 소리와 함께 빛이 켜짐 10) 손전등으로 탐색
손전등 획득 전에는 진행이 막히지 않도록 책상의 희미한 윤곽과 가까운 거리에서의 상호작용 안내를 제공.

5. 손전등 필수 탐색 구간 (이후 챕터 설계): 전등 고장 아파트 복도, 지하 기계실, 폐쇄된 창고, 어두운 계단, 정전된 가정집, 지하 주차장.
단서는 어둠 속에서 자체 발광하지 않음. 손전등을 비춰야 위치·내용 확인 가능.

6. QA: 같은 위치·카메라 방향에서 정상 점등 / 정전+손전등 OFF / 정전+손전등 ON / 부분 소등 / 비상등 비교 (실제 Godot 화면 기준).
기존 손 모델, 카메라 높이, 상호작용 UX, 테이프 탐색 및 전체 QA 수정 요청도 함께 반영.
정전 상태에서도 손전등 없이 원활하게 탐색할 수 있다면 QA FAIL로 처리하고 수정.
