# P0 수정 보고 — 팝업 잘림·클릭 불가 / 문 잠김 이후 진행 불가 (2026-11-27, 빌드 r5)

기준: **자동** = 헤드리스 Godot 연속 회귀 테스트 · **화면** = 리눅스 실제 Godot 화면(CPU 렌더)·실제 X11 마우스/키보드 입력 · **Windows 실기 = 미검수**(개발 환경에 Windows 없음).

## 1. 확인 팝업이 좌상단에 잘리고 클릭되지 않던 문제

**원인 (재현 확인)** — `scripts/ui/confirm_dialog.gd`가 `_ready()`에서 `set_anchors_preset(PRESET_FULL_RECT)`만 호출했다.
Godot 4에서 이 함수는 이미 트리에 들어온 컨트롤의 현재 사각형을 유지하도록 오프셋을 다시 계산한다 → 팝업 루트가 **(0,0) 위치·0×0 크기**로 남았다.
그 안의 띠·글·버튼이 0×0 사각형의 중심(=화면 좌상단 모서리)을 기준으로 배치되어 제목·내용이 화면 밖으로 잘리고, '새 게임' 버튼은 음수 좌표(x −136)에 놓여 눌리지 않았다.
수정 전 빌드 설정(r4)으로 같은 화면을 다시 띄워 확인: 팝업 rect = `P(0,0) S(0,0)`, 버튼 `새 게임 P(-136,18)`. 설정 화면(`settings_menu.gd`)도 같은 코드 패턴이었다.
이 팝업은 '저장이 있을 때 새 게임'에서만 뜨는데, 이전 검수(화면·X11 입력 테스트)가 저장이 없는 상태에서만 새 게임을 눌러 놓쳤다.

**수정**
- `confirm_dialog.gd` 다시 작성: `set_anchors_and_offsets_preset` + `CenterContainer` → 화면 정중앙 카드 (제목 · 질문 · 보충 설명 · [예][아니오]), 사용자 디자인 예시 반영. 창 크기가 바뀌어도 앵커 기준으로 중앙 유지.
- 팝업이 뒤 메뉴·게임 클릭을 막음(MOUSE_FILTER_STOP), 기본 선택 '아니오', ESC = 아니오, 중복 팝업 방지(`open_count`, 호출부 `is_instance_valid(_sub)` 검사), 응답 두 번 처리 방지.
- 팝업·일시정지·타이틀 중에는 상호작용 아이콘(조준점·손) 숨김 (`hud.gd`).
- 마우스 표시·게임 조작 정지는 기존 GameFlow 상태(TITLE/PAUSED)가 담당 → 팝업 닫으면 원래 상태로 복귀 (X11 테스트로 확인).
- 설정 화면 같은 버그 수정 (`settings_menu.gd`).
- 해상도 비례: 프로젝트 `window/stretch/mode = canvas_items` (1920×1080 기준 UI를 창 크기에 맞춰 비례).
- 적용 팝업: 새 게임 · 다시 시작 · 메인 메뉴 · 게임 종료 (모두 같은 컴포넌트).

## 2. 문이 잠긴 뒤 스토리가 진행되지 않던 문제

**원인** — 사용자 플레이 화면을 직접 보지 못해 하나로 단정할 수는 없지만, 코드 점검과 재현 테스트에서 영구 정지 경로 4개를 찾았다.
1. **(가장 유력)** EVENT 05의 '등 뒤 목소리'가 *플레이어가 녹음기를 직접 정지해야만* 발생했다. 정지 방법 안내가 없고(미니멀 UI), 시간 제한도 없어 녹음기를 멈추지 않으면 그 뒤 정전·손전등·잠금 해제가 영원히 오지 않았다.
2. 테이프 재생 중 복도로 나가 있으면 문이 그 뒤에서 잠겨 **작업실 밖에 갇혔다** (손전등·녹음기에 닿을 수 없음).
3. 잠긴 문을 EVENT 04가 끝나기 직전(쾅 직후 0.5초 안)에 시도하면 그 시도는 무시되어, 다시 시도해야 했다.
4. 정전 직후 서랍이 '빛을 받지 않는 물체'로 판정되면 손전등을 꺼낼 수 없었다 (안내광 반경에 의존).
그 밖에 대비: 소은을 손전등으로 비추지 않으면 멈추는 문제(요구사항 17 새 흐름), 괴물 모델이 없을 때 추격이 시작되지 않는 문제.

음성 파일 문제는 원인이 아니다 — 이벤트는 음성 재생 완료 신호를 기다리지 않고 시간 기준으로 진행한다 (최종 음성이 없는 현재도 자막만으로 진행됨, 자동 테스트 확인).

**수정 (출입문 잠금·공포 연출·순서는 그대로)**
- `EV05a_tape_autostop`: 녹음기를 멈추지 않으면 약 9초 뒤 테이프가 끝나 스스로 멈춘다(정지 버튼·철컥). 직접 멈췄으면 건너뜀(`skip_if_started`).
- 문 쾅·잠금은 플레이어가 작업실 안에 있을 때만 (밖이면 돌아올 때까지 기다렸다가 등 뒤에서 닫힘).
- EVENT 05 트리거를 '잠긴 뒤 한 번이라도 문을 시도했는가' 상태로 변경 (일찍 시도해도 인정) + 시도하지 않아도 40초 뒤 진행.
- 손전등을 얻기 전엔 서랍·손전등이 어둠 때문에 막히지 않음.
- 이벤트 디렉터: 신호·조건 트리거에도 `fallback_after`(+`fallback_conditions`) 안전장치, 90초 넘게 대기하는 이벤트는 경고 로그.
- 소은 이벤트 15초 · 추격 시작 12초 · 전환 50초 안전장치, 추격 중 멈춰 서도 괴물이 다가와 '잡힌' 것으로 보고 바로 전환(사망 없음).

**검수 (헤드리스 연속 회귀 95/95)** — 새 게임부터 TAPE 02 삽입·이어하기까지 한 번에:
| 상황 | 결과 |
|---|---|
| 정상 순서 진행 | PASS |
| 재생 중 복도로 나감 → 밖에 갇히지 않음, 돌아오면 문 쾅·잠김 | PASS |
| 잠기자마자 문 시도(이벤트 준비 전) → 두 번째 시도 없이 진행 | PASS |
| 문을 여러 번 시도 → 이벤트 중복 없음 | PASS |
| 녹음기를 멈추지 않음 → 테이프가 스스로 멈추고 진행 | PASS |

| 손전등 획득 후 작업실 다시 탐색 → 문 이벤트가 엉뚱하게 발생하지 않음 | PASS |

| 실제 Windows에서 같은 순서 | **미검수** |

연속 플레이 영상(편집 없음, 소리 포함): 새 게임 → 1998 아파트 진입·TAPE 01 타이틀까지 2분 44초. 이동·조작은 스크립트가 같은 처리 함수를 호출해 입력함(사람이 직접 한 플레이 아님).
