## 화면 검토 중 발견해 고친 문제
1. 사무용 의자가 등받이를 책상 쪽으로 향하게 놓여 있었음 (이전 빌드부터) → 방향 수정
2. 책상 충돌체가 바닥까지 꽉 찬 상자라 책상 아래 물건을 조사할 수 없었음 → 상판 두께만 충돌
3. 앉은 시작 위치에서 의자 충돌체가 플레이어를 밀어 올림 → 앉아 있는 동안 의자 충돌 끄기, 일어날 때 의자와 함께 이동
4. 일어서며 민 의자가 서랍 앞을 막음 → 반대쪽으로 밀기
5. 복도 끝 형체가 계단실 벽 뒤에 있어 보이지 않음 → 복도 안쪽으로 이동
6. 문틈 존재가 문틀 벽 뒤에 서 있었음 → 틈 바로 뒤로 이동, 문 열림 각도 14° → 20°
7. 문이 열려 있으면 EVENT 04가 발생하지 않음 → 열린 문이 스스로 닫히다가 틈만 남기고 멈추도록
8. EVENT 04가 끝나기 전에 녹음기를 멈추면 05가 겹쳐 발생 → 문틈 연출 중엔 05 대기
9. 소은 얼굴 코 밑 검은 자국·눈동자 없음 (위 모델 항목)
