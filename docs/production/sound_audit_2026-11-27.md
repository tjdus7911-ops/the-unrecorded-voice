# 프롤로그 사운드 전수 검수 (요구사항 20) — 2026-11-27

검수 방법
- `tools/ci/sound_audit.sh`: 새 게임 → 프롤로그 → TAPE 01 → 작업실 복귀 → TAPE 02 삽입 → 이어하기까지의 스토리 회귀 테스트를 **실제 오디오 믹싱**(xvfb + Godot Movie Maker)으로 실행. 구간마다 재생 중인 소리 목록(`SOUND@…`)을 남김
- 헤드리스 테스트는 오디오를 믹싱하지 않음(Dummy 드라이버 → 원샷이 끝나지 않음) → 소리 항목은 위 스크립트에서만 판정
- 음원 113개 전수 스캔 (길이·평균 레벨·무음 여부)
- 실제 Windows 스피커/헤드폰 청취: **미검수**

## 발견·수정한 문제

| # | 항목 | 문제 | 수정 |
|---|---|---|---|
| 1 | 녹음기 재생 | 재생 내내 지지직(amb_tape_hiss) 반복 + 2.5~6.5초마다 잡음 튐 → 대사 중에도 잡음 | 반복 잡음 제거. PLAY 직후 0.65~0.85초 지지직 1회(`sfx_tape_start_crackle`, 끝 10 ms 무음)만. 릴 기계음(모터)은 유지 |
| 2 | 녹음 순서 | 고정 시각(5초·9초) 배치 | `tape_sequence`: 앞 소리가 끝난 뒤 다음 — PLAY → 지지직 → '정우야, 잘 들려?' → 놀이터 녹음 → '정우야, 녹음되고 있어?' → 끝나는 순간 문 쾅 |
| 3 | 녹음기 정지 | 정지해도 테이프 속 음성·소리가 계속 재생 | 정지 = 테이프 속 소리 일시정지, 다시 재생 = 이어서. 테이프 자동 정지·작업실 복귀·공간 전환 때 모두 정리 |
| 4 | 반복 음원을 원샷으로 재생 | 되감기(amb_tape_rewind), 녹음 조각 발견음(amb_tape_motor), 1998 테이프 잡음(amb_tape_hiss ×2곳) — **끝나지 않고 영원히 재생** (챕터 전환 뒤에도 남던 잡음의 원인) | 각 호출에 길이 지정·원샷 음원으로 교체. `Sounds`가 반복 음원 원샷 재생을 1.2초로 자르고 경고 → 테스트가 0건 확인 |
| 5 | 형광등 웅웅 | 정전·소등 중에도 계속 | 불이 켜져 있을 때만 (깜빡일 때 함께 끊김) |
| 6 | 괴물 숨소리 | 7초짜리 숨소리·발소리가 추격 종료·1998 진입 뒤에도 남음 | 추격 종료(정적) 순간 괴물 소리 전부 정지, 연출 코루틴도 중단 |
| 7 | 공간 전환 | 작업실·상가 복도 소리가 1998 공간으로 이어질 수 있음 | 진입 시 반복음은 멈춰 두고(복귀 시 재개) 원샷은 끊음 |
| 8 | 일시정지 | 엔진 기본 동작에만 의존 | 일시정지 직전 게임 소리(UI 제외) 일시정지 → 재개 시 그것만 재개 |
| 9 | 잠긴 문 연타 | 같은 프레임에 덜컥 소리 2번 겹침 | 0.35초 간격 (시도 신호는 그대로 전달) |
| 10 | 환경음 페이드 | 빗소리 페이드가 매 프레임 덮어써져 실제로는 끝에서 뚝 끊김 | AmbientEmitter `gain_db`로 실제 페이드 |
| 11 | 녹음 속 놀이터 소리 | `TTS_tape_playground.wav`가 합성 실패로 **완전 무음** | 자체 합성 `PH_tape_playground_bed.wav`(바깥 공기 + 그네 삐걱임, 사람 목소리 없음)로 교체 |
| 12 | 녹음 음성 질감 | VoiceTape 버스 대역·왜곡·떨림이 강함 | 약하게: 저역 260→180 Hz, 고역 4.6→6.5 kHz, 왜곡 0.06→0.03, 떨림 0.9→0.45 ms |
| 13 | 대사·배경 균형 | 녹음 속 놀이터 소리와 대사가 겹침 | 대사가 나오는 동안 녹음 속 배경음 −6 dB |

## 남은 사항
- 대사 음성: 최종 음성 없음(임시 자막). 대사·효과음 음량 균형의 최종 판단은 성우 음성이 들어온 뒤 → **미검수**
- 길이 4초 이상 원샷: 천둥(8~12초, 자연음), 그네 삐걱임(6초, 기억 연출), 괴물 숨소리(7초, 추격 종료 시 끊김), 녹음 속 놀이터(6.3초, 의도) — 모두 의도된 길이로 판단
- 실제 Windows에서 스피커·헤드폰으로 듣는 검수 → **미검수**
