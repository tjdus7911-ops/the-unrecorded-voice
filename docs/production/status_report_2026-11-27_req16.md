# 개발 상태 보고 r4 — 요구사항 16 공식 스토리 반영 (2026-11-27)

기준
- **자동 테스트**: 헤드리스 Godot에서 실제 레벨·플레이어·이벤트를 돌려 상태값을 확인 (`tools/ci/run_tests.sh`).
- **화면 검증**: 리눅스 CPU 렌더(lavapipe, Vulkan)로 실제 Godot 화면을 캡처하거나 영상으로 녹화해 직접 확인.
- **미검수**: 위 두 방법으로 확인하지 못한 항목 (예: 소리를 사람이 직접 듣는 청취 검수, Windows 실기).
- 자동 테스트 통과만으로 플레이 검수 완료로 보지 않습니다.

## 3. §13 확인 항목

| 확인 항목 | 결과 | 방법 |
|---|---|---|
| 소은 대사 직후 문이 닫히는가 | PASS | 대사 길이(`duration_of`) 기준 타이머 → 문 애니메이션 + 쾅 (자동 테스트·영상) |
| 문 닫힘 소리가 문 위치에서 나는가 | PASS(위치) / 청취 미검수 | 3D 소리를 문 안쪽 위치에 배치 — 귀로 듣는 검수는 못 함 |
| 정지 후 3초 뒤 등 뒤 목소리 | PASS | 정지 1초 시점엔 없음, 3초 뒤 플레이어 뒤·방 안 (자동 테스트). 최종 음성 없어 현재는 자막 |
| 손전등 없이 어두운가 | PASS | 실제 화면 캡처 (정전 시 환경광 0) |
| 소은이 자연스럽게 나타나고 사라지는가 | PASS(화면) | 보는 중에는 생기거나 사라지지 않음 (조명이 꺼진 프레임/시야 밖/테이프 잡음 순간만) |
| 괴물이 벽을 통과하지 않는가 | PASS | 몸 좌표가 기둥 뒤·벽 안쪽 범위 (자동 테스트) + 화면 |
| 발소리가 괴물 위치와 맞는가 | PASS(위치) / 청취 미검수 | 발소리 음원 위치 = 플레이어 뒤(지나온 쪽) 추적 지점 |
| 소등 순서 | PASS | CorLight0→4가 지나간 뒤 차례로, 5는 끝에서 (자동 테스트·화면) |
| 1998 전환 | PASS | |
| 복귀 후 테이프 상태 | PASS | tapes_done=[1], 다음=2, 1번 상자 제자리, 2번만 가져가기 가능 |
| 음성 정책 | PASS(규칙) | 최종 파일 없으면 자막만 — 실제 녹음 파일은 아직 없음 |
| 저장·이어하기 | PASS | TAPE 02 삽입 후 저장 → 레벨 재시작 → 녹음기 속 2번·사진·테이프 순서 복원 (자동 테스트) |

- EV10 마지막 소등 뒤 비상구 표시등의 초록빛이 벽 전체를 물들임(네온 느낌) → 마지막 소등 때 표시등도 꺼지도록 수정. **프롤로그 영상은 수정 전 녹화본**(테스트 재실행·빌드는 수정 후).

## 7. 미구현 · 알려진 문제 · 임시 결정
- **최종 음성 없음**: 소은·어린 정우·테이프 대사는 임시 자막만. 음성 파일만 넣으면 코드 수정 없이 재생.
- 효과음 전부 임시 합성(아이 웃음은 무료 TTS 합성). 청취 검수는 사람이 해야 함.
- 소은·괴물 애니메이션: 코드 포즈 수준(서 있기·엿보기). 걷거나 뛰는 모습은 보여주지 않음(대본에도 없음).
- 1998 아파트: 1층 복도·계단실(2층 참)·현관·놀이터만. 나무는 단순 형태, 원경 동은 평면 텍스처.
- 작업실·소품 일부 재질(종이컵·포스트잇·커피·녹음기 빨간 버튼·테이프 필름)이 glTF에서 흰색으로 나오는 기존 문제를 발견 — 원인 수정 함수는 만들었고 아파트에만 적용. 작업실·소품 재빌드는 다음 작업.
- 사용자 결정이 필요한 임시안: `docs/design/open_questions.md` Q-14(복귀 후 작업실 조명·잠김) · Q-15(1998 시간대) · Q-16(녹음 조각 발견 표시) · Q-17(사진 구도: 소은 혼자)
- PHASE 02로 넘어가지 않았습니다 (승인 대기).
