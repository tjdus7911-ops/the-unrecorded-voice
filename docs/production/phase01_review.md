# PHASE 01 실제 게임 화면 검토 기록 (2026-11-26)

검토 방법: Godot 4.7.2 **Forward+ 실제 렌더러**(소프트웨어 Vulkan, lavapipe)로 게임을 실행해 화면을 캡처하고 직접 확인.
자동 테스트 통과는 기능 확인용일 뿐, 아래 문제들은 모두 **실제 화면을 보고** 찾았다.

## 발견 → 수정

| # | 실제 화면에서 발견한 문제 | 원인 | 수정 |
|---|---|---|---|
| 1 | 텍스처 메모리 2.2 GB | 모든 GLB가 같은 텍스처를 각자 임베드 + 헤드리스 임포트에서 비압축 | .gltf + 원본 텍스처 공유 참조, 임포트 기본값 VRAM 압축(BC), 노멀맵 BC5. 재질 텍스처 실측 **약 124 MB** |
| 2 | 창밖이 새까맣게 보임 | 빗물 유리 셰이더가 뒤 풍경을 ALBEDO로 출력 → 어두운 조명이 곱해짐 | 풍경은 EMISSION(무조명), 유리는 반사만 |
| 3 | 손전등을 줍기 전부터 손에 들려 있고 화면을 가림 | 1인칭 모델을 항상 표시, 너무 가까움 | 획득 후에만 표시, 위치 조정 |
| 4 | 손전등 빛이 딱딱한 원 | 스팟 감쇠만 사용 | 자체 제작 프로젝터 패턴(핫스폿·반사판 링·부드러운 감쇠) |
| 5 | 플로어 스탠드 갓이 하얗게 날아감 | 옴니 광원이 갓 안쪽을 과노출 | 아래로 향하는 스팟 + 약한 옴니 (그림자 패스도 2→1) |
| 6 | 블라인드 그림자가 점무늬(모아레) | 가는 살 그림자 + 낮은 블러 | 그림자 블러·노멀 바이어스 증가 |
| 7 | 창 물방울이 별처럼 반짝임 | 물방울 밀도·스펙큘러 과다 | 밀도·반사 감소 |
| 8 | 선반 카세트가 흰 블록으로만 보임 | 밝은 종이 라벨 + 밝은 케이스 | 어두운 스모크 케이스 + 색 띠 라벨 아틀라스 |
| 9 | Blender 렌더가 이전보다 어두움 | 절차 재질 색이 선형값이었고 새 텍스처는 sRGB(물리적으로 정확) | 텍스처 유지, 검토 렌더 노출 +0.6 EV |
| 10 | 소품의 노멀맵이 망치 자국처럼 과함 | 높이→노멀 변환 강도 과다 | 실제 미세 요철 수준으로 축소 |
| 11 | 카세트 창이 검은 판 | 윗판이 통짜 | 창 개구부 4분할, 릴·테이프 보이게 |
| 12 | 메모가 백지 | 높이장 메시 UV가 면마다 0~1 | 전체 UV 매핑 |
| 13 | 문을 열어도 복도로 못 나감 | AnimatableBody가 부모(경첩) 회전을 따라가지 않음 | 충돌체를 레벨에 두고 매 물리 프레임 경첩 변환 동기화 |
| 14 | 상호작용 상자가 이동을 막음 | 조사 판정 상자가 월드 충돌 레이어 | 조사 전용 레이어 + 시야 확인 |
| 15 | 테이프를 넣어도 릴이 안 돔 | 충돌체 이름이 테이프 노드와 같음 | 충돌체 이름에 `_col` |
| 16 | 문이 열려도 복도 소리가 막힘 | 차폐 판정이 1개 경로뿐 | 4경로 비율로 부분 차폐(문틈 회절 근사) |

## 남은 한계 (다음 단계 후보)
- 1인칭 **손** 모델 없음 — 손전등만 표시. 캐릭터 제작 단계(서정우)에서 팔·손 리그와 함께 제작
- 소파·의자 주름은 변위 노이즈 수준 — 봉제선·눌림의 스컬프트 디테일은 수작업이 더 낫다
- 사운드는 전부 합성 임시 음원 — 빗소리·발소리는 실제 녹음/라이브러리로 교체 시 품질 차이가 큼
- 캐릭터 음성은 단일 여성 TTS를 가공한 가이드 — 남성·노인 음색은 부자연스러움. 최종 더빙 필요
- 이 작업 환경에는 GPU가 없어 FPS는 사용자 PC에서 `--benchmark` 로 측정 필요
